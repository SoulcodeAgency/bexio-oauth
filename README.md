# bexio-oauth

Bexio OAuth token custody for Node apps: connect Bexio accounts, store tokens encrypted in Postgres, and get a valid access token anywhere, including background jobs.

> Work in progress. The design is specified in [docs/integration.md](docs/integration.md); the first release is tracked in [#1](https://github.com/SoulcodeAgency/bexio-oauth/issues/1).

- [Integration guide](docs/integration.md): concepts, API, database setup, security model.
- [Development guide](docs/development.md): repo layout, tests, CI/CD.
